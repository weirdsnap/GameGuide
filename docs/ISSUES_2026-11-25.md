# 问题记录 2026-11-25

来源：线上 `api_server.log` 与 `data/turns/` 复查（用户反馈「好像有网络错误」）。

## I-25 流式等待期全程静默，移动网络下断连 → 前端报「网络错误」【P1】

**现象**（2026-11-25 11:56:40，IP 223.104.79.66，iPhone）：

- 11:56:15 `OPTIONS /api/ask/stream` 200，随即进入 agent 工具循环；
- 11:56:15 → 11:56:37 连续 7 次 `POST api.deepseek.com` 全部 200 OK；
- 11:56:40 `WARNING 客户端断开连接`，同一毫秒 access log 记录 `POST /api/ask/stream 200 0`
  ——整个响应体 0 字节；
- 前端 `catch` 分支渲染「网络错误，无法连接到助手服务器」。

**根因**（三层，分开修）：

1. 传输层：SSE 在首 token 前不发任何字节，实测静默可达 65s（elapsed max），中间设备/浏览器把长静默连接判死。
2. 协议层：`multi_agent.ask_stream` 只在 `AIMessageChunk.content` 非空时 yield token；
   工具调用阶段 content 为空（只有 `tool_call_chunks`），所以工具循环全程无事件。
3. 前端：loading 文案静态「思考中…」，断流时 `catch` 覆盖已有内容且无重试入口。

**附带发现（服务器侧待修）**：

- 断连分支 `except (ConnectionResetError, ConnectionAbortedError)` 没有 `quota.refund()`，
  而超时分支有 → 网络原因没拿到答案也扣 1 次额度。
- 断连轮次 `route` 落库为 null、`tokens_in=0`，统计上与正常轮并存无法区分。
- `turns` 无 `first_token_ms`，「静默期」只能靠 elapsed 间接推断。

**方案**：[`STREAM_UX_PLAN.md`](STREAM_UX_PLAN.md)（L0 心跳 / L1 计时文案 / L2 真工具事件 / L3 断流恢复 / L4 断流记账）。

**验收**：`stream_chunks=0` 轮次归零、`first_token_ms` p90 有数、iPhone 移动网络下工具多轮问题不再弹网络错误。

## I-26 四个观测字段恒为 0/NULL：AgentState 漏声明【P1，实证】

**现象**：`turns` 全量 48/48 轮里 `history_raw_msgs` / `history_used_msgs` /
`history_trim_chars` 全为 0，`progress_source` 全为 NULL；`sessions.progress_src` 跟着全空。

**根因**：`multi_agent._build_initial_state()` 把四个值放进了初始 state，但
`graph.AgentState`（TypedDict）里没有这四个字段，LangGraph 按 schema 建 channel，
未声明的 key 在图跑完时被丢弃，`_meta_from_state()` 只能拿到 `.get()` 默认 0。

实证（menu 路径，不调 LLM）：

```
初始 state: {'history_raw_msgs': 2, 'history_used_msgs': 2, 'history_trim_chars': 0, ...}
图终态 keys: ['answer','detected_game','history','history_full','last_game',
              'last_game_confirmed','model_name','prompt','question','usage','verbose']
```

**影响**：上下文裁剪（I-09）的效果从未被记录，只能靠 `tokens_in` 间接看；
`progress_source` 空导致排查「模型为什么认为用户在第二章」时看不到进度来源。

**修法**：`src/rag_agent/graph.py` 的 `AgentState` 补四行声明（Mac 侧），
服务器侧补回归测试：跑 menu 路径断言终态仍带这四个 key。

**验收**：`data/turns` 新轮次里四个字段非零/NULL；`tests/test_context_trim_meta.py` 转绿。
